A note about me

上班做页面，
下班捡像素。

白天是和需求斗智斗勇的前端；晚上是给小狗捡球、给灵感腾位置的普通人。

— 小满，写在周六午后

我喜欢把复杂的东西做得清楚，也喜欢给清楚的界面留一点人情味。过去几年一直在做 Web 前端，最近开始认真经营自己的小产品。

这个博客像一本摊开的速写本：作品是钉在软木板上的卡片，记忆是口袋里的贴纸，近况则是一张张可以翻过的车票。

目前住在杭州。咖啡偏好燕麦拿铁，小狗叫馒头，正在学习 Tauri，也在练习把周末过得慢一点。

经历与近况

A few chapters

2024.09 / FIRST LAUNCH

第一次，把自己的
小产品交给真实用户。

从一张需求便签到正式上线，花了七周。记得发布那晚反复刷新后台，也记得第一位陌生用户说“挺好用的”。那一句，比数据图表更让人开心。

独立上线前端开发第一次反馈

2025.03 / REAL-WORLD TOOL

给真实课堂，
做一件刚刚好的小工具。

听老师讲完一堂课的使用场景，才发现“少一步操作”比“多一个功能”重要得多。那段经历让我学会先观察，再写代码，也学会为不完美的网络环境做设计。

需求访谈小程序用户体验

2025.10 / PIXEL SUNDAY

重新捡起像素画，
也捡回一点耐心。

开始坚持每周画一张小场景。最慢的一张改了六个版本，却让我找回了小时候一点点涂颜色的专注。现在，它们会成为这个博客的定期更新。

像素画每周一张慢下来

NOW / STILL CURIOUS

正在学习 Tauri，
也练习把周末还给自己。

想做一个更轻的桌面小工具，顺便弄懂窗口、文件系统和那些网页之外的知识。工作之外，尽量留一个下午给散步、咖啡和没有截止日期的事情。
